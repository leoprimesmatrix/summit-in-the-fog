# Audio files for Summit in the Fog

Every file here is an original sound effect generated by `tools/gen_sfx.js`.
Rebuild the whole set with:

```bash
node tools/gen_sfx.js
```

The game plays these with `HTMLAudioElement` only. There is no Web Audio API
anywhere in the game code; the generator is an offline Node script.

| File | When it plays |
|---|---|
| `sfx_hop` | Pushing off for a hop |
| `sfx_land` | Landing on a ledge |
| `sfx_echo` | The landing ripple, when momentum opens two or more rows |
| `sfx_slip` | Missing a ledge and falling |
| `sfx_crumble` | Standing on a ledge that starts to give way |
| `sfx_cairn` | Lighting a cairn checkpoint (a soft two-note bell) |
| `sfx_crystal` | Picking up a crystal |
| `sfx_gust` | A gust arrives and parts the fog |
| `sfx_whiteout` | The whiteout catches you |
| `sfx_summit` | Reaching the summit |
| `sfx_ui` | Menu tick |
| `amb_wind` | Quiet looping wind bed during the climb |

To replace any sound, drop in a file with the same name; the loader accepts
`.wav`, `.ogg` or `.mp3`. A missing file is skipped with a console warning.
